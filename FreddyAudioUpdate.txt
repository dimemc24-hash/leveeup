# Cryptid Spell Caster — Build Prompt

## What This Is

A spelling practice web app for a 2nd grader named Freddy. The core problem: Freddy practices spelling by **unscrambling written words** (visual recognition), but his tests require him to **hear a word and write it** (auditory-to-written). The practice modality doesn't match the assessment — so he knows words when he sees them but misspells them when he only hears them.

This app closes that gap by mimicking the real test format: **speak the word aloud → child writes it with a stylus → AI reads the handwriting → gives feedback**.

## Architecture

**Frontend:** React + Vite + Tailwind CSS  
**Backend/OCR:** Supabase Edge Function calling Anthropic API (Claude's vision) to read handwriting  
**Speech:** Web Speech API (browser-native TTS)  
**Input:** HTML Canvas with Pointer Events (stylus/touch/mouse support, pressure-sensitive)

## The Handwriting Recognition Approach

**Do NOT use Tesseract.js.** Tesseract is trained on printed/typed text and performs very poorly on messy child handwriting.

Instead, use **Claude Sonnet's vision capability** via a Supabase Edge Function. The canvas is exported as a PNG data URL, sent to the edge function, which forwards it to the Anthropic API.

### Supabase Edge Function: `recognize-handwriting`

```typescript
// supabase/functions/recognize-handwriting/index.ts
import { serve } from "https://deno.land/std@0.177.0/http/server.ts";

const ANTHROPIC_API_KEY = Deno.env.get("ANTHROPIC_API_KEY");

serve(async (req) => {
  // Handle CORS
  if (req.method === "OPTIONS") {
    return new Response("ok", {
      headers: {
        "Access-Control-Allow-Origin": "*",
        "Access-Control-Allow-Methods": "POST",
        "Access-Control-Allow-Headers": "Content-Type, Authorization",
      },
    });
  }

  try {
    const { imageBase64 } = await req.json();

    // Strip data URL prefix if present
    const base64 = imageBase64.replace(/^data:image\/\w+;base64,/, "");

    const response = await fetch("https://api.anthropic.com/v1/messages", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "x-api-key": ANTHROPIC_API_KEY!,
        "anthropic-version": "2023-06-01",
      },
      body: JSON.stringify({
        model: "claude-sonnet-4-20250514",
        max_tokens: 50,
        messages: [
          {
            role: "user",
            content: [
              {
                type: "image",
                source: {
                  type: "base64",
                  media_type: "image/png",
                  data: base64,
                },
              },
              {
                type: "text",
                text: `You are reading a single handwritten word written by a 7-year-old child using a stylus on a tablet screen.

CRITICAL INSTRUCTIONS:
- The image contains exactly ONE word written in a child's handwriting
- The handwriting will be messy, with inconsistent letter sizes, wobbly lines, and imperfect spacing
- Read the word EXACTLY as the child wrote it, including any misspellings
- Do NOT correct the spelling — if they wrote "relef" output "relef", not "relief"
- Do NOT add punctuation, explanation, or quotes
- Output ONLY the single lowercase word, nothing else
- If letters are ambiguous, make your best guess based on letter shapes
- Common child handwriting quirks: 'a' and 'o' look similar, 'e' and 'i' can be hard to distinguish, letters may be reversed or oddly sized

Output the word now:`,
              },
            ],
          },
        ],
      }),
    });

    const data = await response.json();
    const text = data.content
      ?.filter((block: any) => block.type === "text")
      ?.map((block: any) => block.text)
      ?.join("")
      ?.trim()
      ?.toLowerCase()
      ?.replace(/[^a-z]/g, "");

    return new Response(JSON.stringify({ word: text || "" }), {
      headers: {
        "Content-Type": "application/json",
        "Access-Control-Allow-Origin": "*",
      },
    });
  } catch (error) {
    return new Response(
      JSON.stringify({ error: "Recognition failed", detail: String(error) }),
      {
        status: 500,
        headers: {
          "Content-Type": "application/json",
          "Access-Control-Allow-Origin": "*",
        },
      }
    );
  }
});
```

Set the secret: `supabase secrets set ANTHROPIC_API_KEY=sk-ant-...`

### Frontend OCR Client

```typescript
// src/lib/ocr.ts
const EDGE_FUNCTION_URL = import.meta.env.VITE_SUPABASE_URL + "/functions/v1/recognize-handwriting";
const SUPABASE_ANON_KEY = import.meta.env.VITE_SUPABASE_ANON_KEY;

export async function recognizeHandwriting(canvasDataUrl: string): Promise<string> {
  const response = await fetch(EDGE_FUNCTION_URL, {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "Authorization": `Bearer ${SUPABASE_ANON_KEY}`,
    },
    body: JSON.stringify({ imageBase64: canvasDataUrl }),
  });

  if (!response.ok) throw new Error(`OCR failed: ${response.status}`);
  const data = await response.json();
  return data.word || "";
}
```

## Game Flow

1. **Menu** — Pick a word pack (grouped by spelling pattern)
2. **Play** — For each word:
   - App speaks the word aloud via Web Speech API (rate: 0.75 for clarity)
   - "Hear it again" button to replay
   - "Use in a sentence" button speaks the word in a sentence (just like real tests do)
   - Child writes the word on a canvas with their stylus
   - "Check Spelling" sends the canvas to the edge function
   - Compare OCR result to target word (case-insensitive, strip non-alpha)
3. **Result** — 
   - **Correct:** Cryptid reveal animation (Mothman, Chupacabra, Sasquatch, etc.)
   - **Wrong:** Show what they wrote vs. the correct word + a spelling rule tip + "Try Again" option
4. **Complete** — Score summary showing all words attempted

## Canvas Component Requirements

This is critical for the handwriting recognition to work well:

- Use **Pointer Events** (not touch/mouse events) — this handles stylus, touch, and mouse uniformly
- Support **pressure sensitivity** via `event.pressure` for natural stylus feel
- Canvas resolution should be **2x display size** (retina) for clean OCR input
- Draw a **dashed baseline guide** at ~72% height to help the child write on a line
- **White background** is essential — Claude's vision works much better with dark ink on white
- Line color: **dark (#1a1a2e)** for maximum contrast
- Line width: 4-8px range, pressure-modulated
- Set `touch-action: none` on canvas to prevent scroll interference
- Use `canvas.setPointerCapture(e.pointerId)` on pointerdown for reliable stroke tracking
- Export as PNG data URL via `canvas.toDataURL('image/png')`

## Spelling Tips (show on wrong answers)

When a word is wrong, show a targeted rule reminder:

- **ie/ei words:** `"i before e" — spell it out letter by letter`
- **receive:** `"i before e EXCEPT after c" — r-e-c-e-i-v-e`
- **y→ies plurals:** `"Change the y to i, add -es: baby → babies"`
- **-ed past tense:** `"Just add -ed: yell → yelled"` or `"Drop silent e, add -d: smile → smiled"`
- **friend:** `"This one breaks the rule! f-r-i-e-n-d"`

## Design Direction

- **Dark theme** — deep navy/midnight gradient background
- **Font:** Fredoka (rounded, kid-friendly but not babyish) for UI, Patrick Hand for handwriting-style hints
- **Colors:** Green accents for success, amber for warnings/tips, blue/purple for actions
- **The canvas writing area should be prominent** — it's the main interaction
- **Big touch targets** — this is a tablet app used by a 7-year-old
- **Minimal text** — Freddy wants to hurry, so don't overwhelm with instructions

## Key Anti-Rush Mechanic

The app's structure naturally slows Freddy down:
1. He has to **listen** (can't skip ahead visually)
2. He has to **write by hand** (slower than typing, engages motor memory)
3. He gets **immediate feedback** with a targeted tip (not just "wrong, try again")
4. The **cryptid reward** gives him a reason to care about accuracy over speed

## Testing the OCR

After building, test the edge function independently:
1. Draw a word on the canvas
2. Export canvas to data URL in browser console: `document.querySelector('canvas').toDataURL('image/png')`
3. Call the edge function directly with curl to debug the Claude response
4. If Claude is returning cleaned-up words instead of raw transcription, strengthen the prompt emphasis on "do NOT correct spelling"
